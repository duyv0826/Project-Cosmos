## 3. 核心玩法与核心循环

**类型定位：艺术 / 实验玩法** —— 不以"通关升级"为核心，而以机制创新或情绪叙事为驱动。

### 核心玩法（玩家主要做什么）
> 以下为引导话术，请替换为你的真实机制。至少写 2-3 条。

- [ ] 玩家通过独特的交互/控制方式来"产生"游戏内容（而非消耗）
- [ ] 世界会回应玩家的某个动作/状态（动态反馈）
- [ ] 机制本身承载叙事或情绪（机制即隐喻）

### 核心循环（玩家重复做什么）
> 用箭头写出来。示例：
> 观察世界 → 做出某个微妙操作 → 世界形态/情绪改变 → 产生新可探索内容 → 重复
