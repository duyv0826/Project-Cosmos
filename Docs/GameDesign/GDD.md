### 核心机制 B：影子同步（Shadow Synchrony）
> 已锁定。主题「孤独/疏离」的机制化：**有挑战的探索 + 机制即隐喻**。

**核心规则**：你和「影子」处在同一空间，但影子永远**滞后半拍**模仿你——你无法直接命令它，只能靠**预先设计自己的动作序列**来诱导它完成目标。

**玩家每回合做什么（操作循环）**：
1. 观察：看清关卡布局、目标、影子当前位置。
2. 预演：决定一串动作序列（前后、停顿、转向……序列会同时驱动你和影子）。
3. 执行：按序列移动，影子自动复读你上一拍的输入。
4. 协同/对抗：有些机关需要「你和影子同时站上两个开关」，或影子恰好挡住通路。
5. 重来调整：失败不惩罚，只提示「你们的节奏错位了」，回到重设计序列。

**挑战本质**：难度来自**预先规划**而非手速——你在"心智"上学习如何**诱导一个慢半拍的存在**。

**赢／情绪收尾**：胜利＝和影子一起抵达「被光照亮的地方」＝你们终于同步了一次；但终局影子仍停在半拍之外，呼应「亲密中的缝隙」。玩家带走的是"那一次接近的瞬间"。

### 核心循环（玩家重复做什么）
> 观察世界／关卡 → 设计动作序列（诱导影子）→ 执行并看影子半拍回应 → 世界因你们发生改变 → 出现新的可探索内容 → 重复

## 4. 美术风格

> 你是互动媒体艺术方向，这里是你最有表达空间的部分。

- **整体色调**：冷峻为主的低饱和配色（深蓝、灰紫、暗青），以**暖色的"光点"**作为情绪高光——"抵达被照亮的地方"是唯一的暖色，强化连接与疏离的对比。
- **美术方向**：2D → **剪影 + 极简几何**。玩家与影子都是抽象剪影，环境用干净色块与轮廓线表现，减少装饰噪音，让"滞后半拍"的运动关系成为视觉主角。
- **影子表现**：影子与玩家共用轮廓、但色相偏冷、半透明，位置总在空中“慢半拍”——从画面上就让玩家一眼看懂"它跟着我，却不在我的位置"。
- **镜头/演出**：固定稍俯视的 Grid 视角（贴合走格制），切关用光的明暗过渡；"同步成功"时以一次扩散光晕视觉化连接瞬间。
- **参考 / 启发作品**：
  - *Journey* — 极简氛围、以光和环境传情，无文字的叙事手法
  - *INSIDE* — 剪影 + 低饱和世界，孤独与压抑的氛围控制
  - *纪念碑谷* — 色块与几何构图带来的静谧与幻觉边界

## 6. 关卡设计（初稿）

> 三段式难度曲线（对应机制 B）：**引入 → 展开 → 转折**。每关目标都是"抵达被光照亮的地方"。

### 空间 A · 引入（学会"同步"）
- 目标：让玩家理解"影子滞后一拍"。
- 布局：一条从起点延伸到光点的直路，必经一扇**单人门**（只要玩家站上去就开）。
- 情绪：**好奇 + 初次巧合的同步感**。玩家不小心发现"我踩开关，影子在门边"，第一次体验"连接"。
- 示意图：
  ```
  [玩家] [ ]
  ...
  [影子目的地] [光点] [门]     ← 直路，无分叉
  ```
- 关卡完成：经历 1-2 次"影子自然跟上"，形成基础认知。

### 空间 B · 展开（强制协同）
- 目标：让玩家主动**利用**影子（从"发现"到"使用"）。
- 布局：出现**并联双开关**——门同时要求「玩家踩 A」+「影子停在 B」。
  ```
  [开关A]---[门]---[光点]
    ↑ 玩家站此
  [开关B]---------------[影子到 B]
  ```
  玩家需先走到 A，让影子滞后落在 B → 门开。
- 情绪：**由"巧合"转为"掌握"**，产生"我学会了和影子配合"的成就感。
- 引申设计：加入岔路逼玩家**逆向推理**——为了让影子停在 B，我现在该站到哪。

### 空间 C · 转折（情绪反转）
- 目标：打破"一切可协同"的预期，埋下疏离情绪。
- 布局：出现一个**"不听话的影子"节点**——某处机关要求影子前进，但它因关卡规则停在"半拍之外"不跟随（诱导规则暂时失效）。
- 情绪：**失落的微见底**——玩家第一次感到"即使学会了，也存在够不到的距离"，呼应主题核心。
- 设计含蓄：不做惩罚，只做"幅度错位"，让玩家体感那份疏离。

> 每段之间以"到达光点"的同步闪光作为情绪节拍与存档检查点。
