## 3. 核心玩法与核心循环

**类型定位：艺术 / 实验玩法** —— 不以"通关升级"为核心，而以机制创新或情绪叙事为驱动。

### 核心玩法（玩家主要做什么）

- [x] 玩家通过独特的交互/控制方式来"产生"游戏内容（而非消耗）

- [x] 机制本身承载叙事或情绪（机制即隐喻）

### 核心机制 B：影子同步（Shadow Synchrony）
> 已锁定。主题「孤独/疏离」的机制化：**有挑战的探索 + 机制即隐喻**。

**核心规则**：你和「影子」处在同一空间，但影子永远**滞后半拍**模仿你——你无法直接命令它，只能靠**预先设计自己的动作序列**来诱导它完成目标。

**玩家每回合做什么（操作循环）**：
1. 观察：看清关卡布局、目标、影子当前位置。
2. 预演：决定一串动作序列（前后、停顿、转向……序列会同时驱动你和影子）。
3. 执行：按序列移动，影子自动复读你上一拍的输入。
4. 协同/对抗：有些机关需要「你和影子同时站上两个开关」，或影子恰好挡住通路。
5. 重来调整：失败不惩罚，只提示「你们的节奏错位了」，回到重设计序列。

**挑战本质**：难度来自**预先规划**而非手速——你在"心智"上学习如何**诱导一个慢半拍的存在**。

**赢／情绪收尾**：胜利＝和影子一起抵达「被光照亮的地方」＝你们终于同步了一次；但终局影子仍停在半拍之外，呼应「亲密中的缝隙」。玩家带走的是"那一次接近的瞬间"。

### 核心循环（玩家重复做什么）
> 观察世界／关卡 → 设计动作序列（诱导影子）→ 执行并看影子半拍回应 → 世界因你们发生改变 → 出现新的可探索内容 → 重复
