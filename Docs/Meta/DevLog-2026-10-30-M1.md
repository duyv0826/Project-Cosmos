## 2. 验收结果

- 无头逻辑：`dotnet run` → **18/18 PASS**，逐拍位置与 `LevelDesign-M1-ShadowRoom.md` 的表逐行一致。
- Unity：批处理编译 **零 error、零 warning**，场景 `Assets/Scenes/ShadowRoom.unity` 已生成并写入 Build Settings。
- 目视：`PreviewCapture` 渲出开局 / 同步两个瞬间，构图与配色确认可用（HUD 为屏幕文本，不进相机渲染）。

## 3. 过程中抓到并修掉的两个真问题

1. **墙体表漏了 `(3,2)`**。文档断言"A 的四邻只有 B 是通路"，但少一堵墙就等于给玩家留了绕过影子开关的后门，
   唯一解被破坏。是无头验收里的"邻格计数"断言先炸出来的，肉眼看不出来。
2. **构造出的对象没挂在视图下**。`Room` / `Actors` 根节点成了场景孤儿，第二次截图时上一张的玩家还留在起点，
   看起来像"影分身"。已 `SetParent(transform)`。

## 4. 待人工过目的（自动化测不到）

- 一格一步的**手感**：`ShadowRoomView.stepSeconds = 0.09`，太快没顿感、太慢烦。
- 玩家是否能在**没有提示**的情况下自己发现"影子慢半拍"（教学节拍 1）。
- 拍 4 的同步光晕强度是否够——现在是一次 0.75 秒的扩散方块。

## 5. 怎么跑

1. Unity Hub 打开 `Project-Cosmos` 目录（Unity 6 LTS，6000.0.23f1）。
2. 打开 `Assets/Scenes/ShadowRoom.unity`，按 Play。
3. WASD / 方向键走格，`R` 重来。撞墙不消耗拍。
4. 不想开 Unity 只想验逻辑：`cd Tools/CoreSimCheck && dotnet run`。
